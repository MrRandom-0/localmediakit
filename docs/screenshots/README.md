# Screenshots to capture before launch

The README links to images in this folder. They have deliberately **not**
been faked or generated — capture real ones from the running app:

1. `home.png` — the home page at desktop width, showing the tool cards.
2. `image-studio.png` — Image Studio with 3–4 photos processed, showing
   before/after sizes and the savings total.
3. `metadata.png` — Metadata Stripper showing a GPS warning on a throwaway
   test photo (take one outside a random public place — never your home).
4. `video-studio.png` — Video & Audio Studio mid-job or with a finished
   result and its download button.
5. `subtitles.png` — Subtitle Tools with a small sample file converted.

Tips: use the same throwaway sample files for all of them, keep each image
under ~500 KB (run them through Image Studio itself), and capture a dark-mode
variant of the home page as `home-dark.png` if you have time.
